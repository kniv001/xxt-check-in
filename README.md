# 学习通签到助手 · 浏览器版(学生端)

多账号学习通签到工具 —— 浏览器形态。服务端跑在本机,手机/电脑浏览器直接用,无需装 APK。

## 运行

**Windows 双击(推荐)**
- `run.bat` —— 后台启动(HTTPS + 局域网),打印电脑/手机访问地址;启动器窗口可直接关,服务在后台
- `stop.bat` —— 停止服务

**命令行**
```bash
python server.py                    # 只绑本机:https://127.0.0.1:8787(无 --https 时为 http)
python server.py --lan --https      # 手机用(打印带令牌的地址;摄像头需 HTTPS)
python server.py --lan --port 9000
```

依赖:Flask、requests、OpenCV(二维码图像解码)、numpy、cryptography(HTTPS 证书)—— 本机已具备。

## 功能

| 组 | 内容 |
|---|---|
| 签到监测 | 逐账号轮询进行中签到(5/10/15/30s),命中自动拉签到页判已签/未签,课程筛选,新签弹提醒 |
| 五类型签到 | 普通=一键;二维码=上传截图/粘贴文本(服务端 OpenCV 识别);位置=坐标+地址;手势/签到码=输入→预校验→提交 |
| 批量扫码 | 一张二维码图 → 全部有效账号并发提交(二维码签) |
| 账号 | 短信/密码登录、cookie 导入、有效性巡检、备注 |

## 边界(与手机 App 同一纪律)

- **仅学生端白名单接口**(活动列表 / 签到页 / 签到提交 / 码预校验),教师端接口一律不收录 —— 见 `xxt_api.py` 头部。
- 已签判定只认页面 `zsign_success`;提交响应契约 `success`/`success2`;`validate_`/`checkFace_` 如实上报不绕过。
- 数据只存本机 `data/accounts.json`(含 cookie,**勿外传/勿入库**)。

## 手机摄像头扫码(安全上下文)

浏览器规则:摄像头(`getUserMedia`)只在**安全上下文**开放 —— `https` 或 `localhost`。局域网明文地址(如 `http://10.22.72.4:8787`)下浏览器**不会**给摄像头,页面会弹提示并引导走相册上传。

### 方案 A:HTTPS(不插线,推荐)

```bash
python server.py --lan --https
```

- 首次启动自动生成本地 CA(`certs/ca.crt`)+ 服务器证书(SAN=本机当前全部 IP,换 IP 自动重签);
- **手机装 CA(一次)**:设置 → 安全 → 加密与凭据 → 安装证书 → **CA 证书** → 选 `ca.crt`
  (可从 `Download/xxt-web-ca.crt` 选,或手机浏览器开 `https://<IP>:8787/ca.crt` 下载);
  装完 Android 会常驻"网络可能受到监控"提示,属用户 CA 的正常现象;
- 然后手机开 `https://<IP>:8787/?k=<令牌>` → 摄像头可用,不依赖 USB;
- 不装 CA 也行:点"高级 → 继续前往",但**部分浏览器在证书告警页面下仍禁用摄像头**,装 CA 最稳;
- 令牌持久化在 `data/.token`,重启不变,书签可长期用。

### 方案 B:adb reverse(USB 隧道,零证书)

```bash
adb reverse tcp:8787 tcp:8787      # USB 连着即可;adb 重启后需重跑
```

手机开 **`http://127.0.0.1:8787`**(localhost = 安全上下文),同摄像头可用,且不过局域网。

> 两方案的二维码识别都在**服务端 OpenCV** 做(页面每 ~0.9s 回传一帧),不依赖浏览器自带识别。
> 入口:「二维码签」弹窗里的 📷(识别后自动提交本条);工具页的 📷(识别后全员提交)。

## 连不上排查(手机/其它设备访问)

1. **用对地址**:`http://<电脑局域网IP>:8787/?k=<令牌>`(启动时打印,多网卡就逐个试)。
   手机上的 `127.0.0.1` 指手机自己,必然被拒。
2. **同一网络**:手机与电脑连同一个 Wi-Fi;手机走流量打不开。
3. **症状对照**:
   - `拒绝连接` = 端口没监听 / 绑错地址(确认启动日志有 `Running on all addresses`)。
   - `一直转圈/超时` = 防火墙或不在同一网络。
   - `缺少访问令牌` = 地址漏了 `?k=`。
4. **防火墙**:症状为超时时,管理员终端执行
   ```
   netsh advfirewall firewall add rule name="xxt-web" dir=in action=allow protocol=TCP localport=8787
   ```
   (本机已检测到 python 的放行规则时无需重复添加。)
5. **IPv4 不通试 IPv6**(校园网/CERNET 常给全球 IPv6):
   ```
   python server.py --lan --host ::
   ```
   手机开 `http://[电脑IPv6]:8787/?k=<令牌>`(IPv6 字面量要用方括号)。

## 安全

- 默认只绑 `127.0.0.1`;`--lan` 时生成访问令牌(URL 带 `?k=`),局域网内仅凭令牌访问;明文 HTTP,同网段设备可达,勿在不可信网络长期开放。
- 浏览器定位(位置签)仅在 https/localhost 可用;局域网 http 下请手填坐标。
