# 学习通签到助手 · 浏览器版

多账号学习通签到工具 —— 浏览器形态。服务端跑在本机,手机 / 电脑浏览器直接用,无需安装 App。

## 功能

| 组 | 内容 |
|---|---|
| **签到监测** | 逐账号轮询进行中的签到(5/10/15/30 秒可选);自动判定"已签 / 未签";课程筛选;发现新签弹出提醒 |
| **五类型签到** | 普通(一键提交) · 二维码(扫一扫 / 上传截图 / 摄像头) · 位置(定位 + 地址) · 手势(九格序号串) · 签到码(4-8 位数字) |
| **批量扫码** | 一张二维码图 → 全部有效账号并发提交(16 并发);失败的可用新码重试 |
| **账号管理** | 短信 / 密码登录;cookie 导入;有效期巡检;备注 |
| **其他** | 二维码图像识别在服务端完成(OpenCV,含放大/补边重试);操作日志面板;账号数据纯本地存储 |

## 部署与运行

### Windows 一键(推荐)

| 文件 | 作用 |
|---|---|
| `run.bat` | 后台启动(HTTPS + 局域网),窗口内打印电脑 / 手机访问地址;启动器窗口可关,服务在后台 |
| `stop.bat` | 停止服务 |

### 命令行

```bash
python server.py                    # 只绑本机(https 或 http://127.0.0.1:8787)
python server.py --lan              # 绑 0.0.0.0,供手机浏览器访问(生成访问令牌)
python server.py --lan --https      # 手机端要用摄像头时必须加(见下)
python server.py --lan --https --port 9000
```

| 参数 | 说明 |
|---|---|
| `--lan` | 绑定 `0.0.0.0`,生成 / 复用访问令牌,打印带令牌的访问地址 |
| `--https` | 启用 HTTPS(本地 CA 自签,自动生成证书;手机摄像头必需) |
| `--host` | 手动指定绑定地址(如 `::` 走 IPv6) |
| `--port` | 端口,默认 `8787` |

### 依赖

```
Flask · requests · OpenCV(opencv-python) · numpy · cryptography
```

## 配置说明

| 项 | 位置 / 规则 |
|---|---|
| 账号数据 | `data/accounts.json`(含登录态,仅存本机) |
| 访问令牌 | `data/.token`;首次以 `--lan` 启动时生成,之后持久不变(手机书签可长期用) |
| HTTPS 证书 | `certs/` 下自动生成:**本地 CA 长期有效** + 服务器证书(SAN=本机当前全部 IP,换 IP 自动重签) |
| 默认端口 | `8787` |
| 摄像头 | 浏览器要求安全上下文:HTTPS 或 localhost。局域网访问请加 `--https` |

## 手机端使用

1. 电脑运行 `run.bat`(即 `--lan --https`),记下窗口里打印的 `https://<IP>:8787/?k=<令牌>`
2. 手机首次需安装 CA:`certs/ca.crt`
   设置 → 安全 → 加密与凭据 → 安装证书 → **CA 证书** → 选择该文件
   (也可手机浏览器打开 `https://<IP>:8787/ca.crt` 下载后安装)
3. 手机浏览器打开上面的地址(建议存为书签),即可使用全部功能,包括 **📷 摄像头扫码**

> 备选:USB 连接时执行 `adb reverse tcp:8787 tcp:8787`,手机访问 `http://127.0.0.1:8787` 亦可(无需证书)。

## 项目结构

```
server.py            Flask 应用:账号 / 监测引擎 / 签到 / 批量 / 图像解码 API
xxt_api.py           协议层(学生端接口封装:登录、活动列表、签到页、提交、码校验)
static/index.html    单页界面(移动端适配,无外部依赖)
run.bat / stop.bat   Windows 启动器 / 停止器
data/                运行数据(账号、令牌)—— 首次运行自动创建
certs/               HTTPS 证书 —— 首次带 --https 启动自动创建
```
